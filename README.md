# 🎓 Student Grade Calculator

A simple Java console-based application that calculates a student's total marks, percentage, and grade based on the marks entered for each subject.

## 📌 Features

- Accepts the number of subjects
- Accepts marks for each subject
- Calculates total marks
- Calculates percentage
- Displays the student's grade
- Simple and beginner-friendly Java program

## 🛠️ Technologies Used

- Java
- JDK 21
- VS Code

## ▶️ How to Run

### 1. Compile the program

```bash
javac StudentGradeCalculator.java

2. Run the program
java StudentGradeCalculator
